Goal: Add a `-w` / `--qwen` flag that routes the request to the "Qwen3 Coder 30B A3B" model hosted on AWS Bedrock, alongside the existing Claude models.

Steps:

1. Extend configuration (`./config/config.go` — existing Config struct/loader):
   - Add fields to `Config`:
     - `AWSRegion string` (config key `aws_region`, default `us-west-2`)
     - `AWSAccessKeyID string` (config key `aws_access_key_id`, optional; empty = use default AWS credential chain)
     - `AWSSecretAccessKey string` (config key `aws_secret_access_key`, optional)
     - `QwenModelID string` (config key `qwen_model_id`, default `qwen.qwen3-coder-30b-a3b-v1:0`)
   - Register these keys in the existing get/set/list config handling and defaults so `y config aws_region eu-central-1` works.

2. Create Bedrock client (`./api/bedrock.go`) implementing `api.Client`:
   - `type BedrockClient struct { region string; accessKeyID string; secretAccessKey string; modelID string; maxOutputTokens int; thinkBudget int; inputPrice float64; outputPrice float64 }`
   - `func (c *BedrockClient) Init(cfg *config.Config)` — copy region, credentials, model id, `cfg.MaxTokens`, `cfg.ThinkBudget`; set prices (input `0.15`, output `0.60` per 1M tokens).
   - `func (c *BedrockClient) GetModelName() string` — returns `c.modelID`.
   - `func (c *BedrockClient) calculateCost(inputTokens int64, outputTokens int64) float64`
   - `func (c *BedrockClient) buildMessages(transaction logic.Transaction) ([]types.Message, int, error)` — one user message whose `ContentBlockMemberText` blocks are `api.Serialize(path)` for each `transaction.Context` entry followed by each `transaction.Request` entry; returns block list and file count.
   - `func (c *BedrockClient) Call(transaction logic.Transaction, think bool, systemPrompt string) (string, error)`:
     - Load AWS config via `config.LoadDefaultConfig(ctx, awsconfig.WithRegion(c.region))`, and `awsconfig.WithCredentialsProvider(credentials.NewStaticCredentialsProvider(...))` when both key fields are set (alias the AWS config package to avoid clash with `yact/config`).
     - Create `bedrockruntime.NewFromConfig(...)` and call `Converse` with `ModelId`, `Messages`, `System` (`types.SystemContentBlockMemberText`) when `systemPrompt != ""`, and `InferenceConfiguration{ MaxTokens: aws.Int32(int32(c.maxOutputTokens)) }`.
     - Ignore `think` (unsupported) but print a notice when true.
     - Print model/file count, elapsed time, token usage, cost, and the max-token warning, mirroring `ClaudeClient.Call`.
     - Concatenate text output blocks from `output.Output` (`*types.ConverseOutputMemberMessage`), trim, `logic.PutBuffer(trimmed)`, return it.
     - Return descriptive error if region is empty or the API call fails.

3. Select client by model (`./commands/call.go`):
   - Add `func newClient(cfg *config.Config) api.Client` — returns `&api.BedrockClient{}` when `strings.ToLower(cfg.ClaudeModel) == "qwen"`, otherwise `&api.ClaudeClient{}`.
   - In `callClaudeAPI`, replace direct `&api.ClaudeClient{}` construction with `client := newClient(cfg)` then `client.Init(cfg)`.
   - Change the non-quiet banner to `fmt.Printf("Sending request...\n")` plus existing model line.

4. Add CLI flag (`./main.go`):
   - `qwenFlag := flag.BoolP("qwen", "w", false, "Use Qwen3 Coder 30B A3B on AWS Bedrock")`
   - Change signature to `func getModelOverride(fable, opus, sonnet, haiku, qwen bool) string` and return `"qwen"` when `qwen` is true (checked before the Claude models).
   - Pass `*qwenFlag` in the `getModelOverride(...)` call.

5. Update help text (`./commands/help.go`):
   - In `printHelpFooter()` add line: `  -w, --qwen                           Use Qwen3 Coder 30B A3B (AWS Bedrock)`.

6. Dependencies (`./go.mod`, `./go.sum`):
   - Add `github.com/aws/aws-sdk-go-v2`, `github.com/aws/aws-sdk-go-v2/config`, `github.com/aws/aws-sdk-go-v2/credentials`, `github.com/aws/aws-sdk-go-v2/service/bedrockruntime` (run `go get` / `go mod tidy`).
