commands/narrow.go
==========
Goal: Add a `narrow` command that removes files from the context list in `.yact/prompt.txt` when their paths do not appear verbatim in the saved prompt text. The prompt and the remaining files are kept.

Steps:

1. Create the narrow command (commands/narrow.go) with the following functions:
   - `HandleNarrowCommand() error`
     - Loads the transaction with `logic.LoadTransaction()`.
     - Returns an error if there is no saved prompt (`Request` is empty or blank), so the command does not wipe the whole context by accident.
     - Calls `narrowContext` with the prompt text, which is `Request[0]`.
     - Stores the kept files in `transaction.Context`.
     - Saves with `transaction.Save()`.
     - Prints each removed file as "Removed: <path>".
     - Prints a summary line with the number of files kept and removed.
   - `narrowContext(context []string, prompt string) (kept []string, removed []string)`
     - Keeps a path only if `strings.Contains(prompt, path)` is true.
     - Preserves the original order.
     - Returns non-nil empty slices when nothing is kept or removed.

2. Register the command in main.go (`main()` switch on `command`):
   - Add `case "narrow":`.
   - Call `requireNoArgs("narrow", commandArgs)`.
   - Set `commandErr = commands.HandleNarrowCommand()`.
   - Place the case next to the "new" and "commit" cases.

3. Document the command in commands/help.go (`printHelpHeader()`):
   - Add this line to the Commands list, aligned with the existing entries: `narrow    Remove files from the task context that are not referenced verbatim in the prompt`.

No other files are needed.
