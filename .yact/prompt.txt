==========
Goal: Add a `-w` / `--qwen` flag that routes the request to the "Qwen3 Coder 30B A3B" model hosted on AWS Bedrock, implemented as a second `api.Client` alongside the existing Claude client.

Steps:

1. Update dependencies (./go.mod)
   - Add requires:
     - `github.com/aws/aws-sdk-go-v2`
     - `github.com/aws/aws-sdk-go-v2/config`
     - `github.com/aws/aws-sdk-go-v2/service/bedrockruntime`
   - (`./go.sum` will be regenerated by `go mod tidy`.)

2. Extend configuration (./config/config.go)
   - Add constants:
     - `BedrockModel = "qwen.qwen3-coder-30b-a3b-v1:0"`
     - `AWSRegion = "us-west-2"`
   - Extend `type Config`:
     - `BedrockModel string \`json:"bedrock_model"\``
     - `AWSRegion string \`json:"aws_region"\``
   - Update `DefaultConfig()` to set both new fields.
   - Keep `Load()` behavior; after unmarshal fill empty `BedrockModel` / `AWSRegion` with defaults.

3. Share request-building logic (./api/client.go)
   - Add `func BuildUserBlocks(transaction logic.Transaction) ([]string, int, error)`
     - Serializes every path in `transaction.Context` via `Serialize`, appends every entry of `transaction.Request`, returns blocks and file count.
   - Add `func FormatCost(inputTokens int64, outputTokens int64, inputPrice float64, outputPrice float64) float64`
   - Keep `Client` interface unchanged.

4. Implement Bedrock client (./api/bedrock.go) — new file
   - `type BedrockClient struct { region string; model string; maxOutputTokens int; inputPrice float64; outputPrice float64 }`
   - `func (c *BedrockClient) Init(cfg *config.Config)` — set region, model id, max tokens, prices (input 0.22, output 0.95 per 1M).
   - `func (c *BedrockClient) GetModelName() string`
   - `func (c *BedrockClient) Call(transaction logic.Transaction, think bool, systemPrompt string) (string, error)`
     - Load AWS config: `awsconfig.LoadDefaultConfig(ctx, awsconfig.WithRegion(c.region))`; return descriptive error if credentials/region missing.
     - Create `bedrockruntime.NewFromConfig(awsCfg)`.
     - Build one user message from `BuildUserBlocks` using `types.ContentBlockMemberText`.
     - Set `System` with `types.SystemContentBlockMemberText` when `systemPrompt != ""`.
     - Set `InferenceConfig: &types.InferenceConfiguration{MaxTokens: aws.Int32(int32(c.maxOutputTokens))}`.
     - If `think` is true, print a note that extended thinking is unsupported for this model.
     - Call `client.Converse(ctx, input)`; extract text from `*types.ConverseOutputMemberMessage`.
     - Print duration, token usage (`resp.Usage.InputTokens` / `OutputTokens`), cost via `FormatCost`, stop-reason warning when `types.StopReasonMaxTokens`.
     - Trim result, `logic.PutBuffer(trimmed)`, return.
   - `func (c *BedrockClient) calculateCost(inputTokens int64, outputTokens int64) float64`

5. Select client by model override (./commands/call.go)
   - Add `func newClient(cfg *config.Config) api.Client`
     - Returns `&api.BedrockClient{}` when `strings.ToLower(cfg.ClaudeModel) == "qwen"`, else `&api.ClaudeClient{}`; calls `Init(cfg)`.
   - Rename/refactor `callClaudeAPI` to `func callLLM(transaction logic.Transaction, think bool, quiet bool, cfg *config.Config, systemPrompt string) (string, error)` using `newClient(cfg)` and printing `Model: <client.GetModelName()>`.
   - Update `HandleActCommand` call site to `callLLM(...)`.

6. Add CLI flag (./main.go)
   - `qwenFlag := flag.BoolP("qwen", "w", false, "Use Qwen3 Coder 30B A3B model on AWS Bedrock")`
   - Update `func getModelOverride(fable, opus, sonnet, haiku, qwen bool) string` to return `"qwen"` when `qwen` is set.
   - Pass `*qwenFlag` at the call site.

7. Document the flag (./commands/help.go)
   - In `printHelpFooter()` add line: `  -w, --qwen                           Use Qwen3 Coder 30B A3B model (AWS Bedrock)`.

8. Expose new config keys (./commands/config.go)
   - In `HandleConfigCommand`: print `bedrock_model` and `aws_region` in the no-arg listing.
   - Add `case "bedrock_model": cfg.BedrockModel = value` and `case "aws_region": cfg.AWSRegion = value` to the setter switch.
