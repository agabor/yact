Install and run

What you need to try YACT. The README has every command, flag and setting.

What you need

  • Your own Anthropic API key, from console.anthropic.com
  • A project in a git working tree, so you can review and revert what YACT writes
  • Go 1.26 or newer, only if you build it yourself

Install

Prebuilt binaries of v0.12.0 for Linux, macOS and Windows are on the releases page. On Linux and macOS:

chmod +x yact-linux-amd64
mkdir -p ~/.local/bin
mv yact-linux-amd64 ~/.local/bin/y

On Windows, put yact-windows-amd64.exe in a folder on your PATH, renamed to y.exe. Or build it from source:

git clone https://github.com/agabor/yact.git
cd yact
go build -o y .
mv y ~/.local/bin/

Releases do not include checksums. If you need to verify what you run, build from source. y --version shows the installed version.

Configure

y config anthropic_api_key <your-own-key>
y config

YACT reads the key only from ~/.yact/config, not from the environment. The first time you run a command, YACT downloads its system prompt from the repository into ~/.yact/systemprompts/.

Commands

CommandWhat it does
y newStarts an empty prompt
y prompt "…"Appends text to the prompt
y read <file>Links files; a quoted pattern such as "src/*.go" links every match
y keyword <word>Links every file that contains the word
y planWrites or updates the plan in yact-prompt.md
y actImplements the plan, or the prompt, and writes the files
y askAnswers a question about the linked code
y reviewReviews a linked diff against the prompt
y analyzeReports where the linked code breaks the code principles
y bashPrints shell commands to read and run yourself
y commitWrites the files of the last response, for example after -o print

Useful flags, written before the command: -m sonnet (or opus, fable) uses a stronger model for one call; --dry-run lists the files that would be sent and makes no call; -o print prints a response instead of writing files.

Linking files

Only links send files. A path mentioned in prose sends nothing.

  • [text](path) and [[path]] link one file.
  • ((word)) links every file that contains the word, searched on every call. It matches whole words in any naming style: ((plan step)) finds PlanStep and plan_step.
  • A line of dashes splits yact-prompt.md: links above it select files but are not sent as text; the text below it is the prompt. y read and y keyword write their links above that line.

Files in vendor, node_modules, .yact and .git are never sent; y config ignore <folder> adds more. Other hidden files are sent if you link them, so do not link secrets such as .env. A link YACT cannot send is printed before the call as Unresolved: <path>, which is expected for a file the plan will create.

In a team

Commit the settings in .yact/ (extensions, ignored folders, an optional domain.txt that describes the project) and ignore the rest:

.yact/temp
.yact/batch_job_id.txt

Agree on how a plan reaches the reviewer: committed with the change, or pasted into the pull request.

Cost

YACT is free. You pay Anthropic for the tokens. Each call prints its token counts and an estimated cost, calculated locally from fixed rates. -b submits a call as a batch job at half the price, and y batch fetches the result later.

When something goes wrong

Claude API key not configured
Set your key with y config anthropic_api_key <your-own-anthropic-key>.
no system prompt found for command
The prompt could not be downloaded. Check the command name and your connection, or create the file in ~/.yact/systemprompts/.
file … is not linked in the prompt
The response wrote a file that the prompt and the plan do not link. That file was not written; the others were. If it belongs in the change, link it with y read or in the plan, and run the command again.
unknown flag: --strict
--strict, --verbose and --skill were removed. Leave them out of the command line. If the error starts with prompt 'act' flags, your copy of the prompt is old: run y download prompt act. To read what act would produce without writing it, use -o print; to see what it would send, use --dry-run.
act command takes no arguments
Prompt commands no longer take the prompt as an argument. Write it with y prompt "…" first, then run the command without one.
no plan found in yact-prompt.md
yact-prompt.md is missing or empty. Write a prompt with y prompt "…" or in an editor.
Files needed as context are missing
The plan has a ## Missing context section. Run y plan once more, or add the files yourself with y read or y keyword.
Assumptions are still open
An entry under ## Assumptions has an open box and no answer. Tick the box if you accept the entry, or write an Answer: line under it and run y plan.
Answers under assumptions are not applied yet
You answered an assumption but have not planned again. Run y plan, read the rewritten entry and tick it.
A ticked assumption is open again
The model reworded the entry, so YACT did not keep your tick. Read the new wording and tick it again.
Unresolved: …
A link points to a file that does not exist (expected for a file the plan creates), to a file in a skipped folder, or is a [[pattern]], which no longer expands. Otherwise fix the path, or link the matching files with y read "<pattern>".
The plan is only partly implemented, or the response is cut off
The plan is too large for one call. Run y plan to drop the finished steps and y act again, and plan smaller goals next time.
A file was not sent
Only links send files. Run with --dry-run, and check that the path is relative to the project root and not in a skipped folder.

The README lists more, Limitations covers what YACT does not do, and you can open an issue.
