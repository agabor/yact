Known issues

YACT's lint is not a proof, and the model it relies on has limits of its own. This page lists the limitations that are known, what causes them, and how to work around them. It is not a bug tracker: open an issue for anything not listed here.

  • The missing-context loop

The missing-context loop

In rare cases, y plan can get stuck re-listing the same files under ## Missing context without changing the plan in any other way.

Cause. YACT keeps no conversation history: each y plan call is a single, independent request, so the model has no memory of having asked for those files before. If the linked files already answer what it is asking for and it does not recognize that, it asks for the same files again instead of moving the plan forward.

Symptom. Running y plan repeatedly leaves ## Missing context unchanged — the same files, sometimes reworded — while nothing else about the plan progresses.

Fix. Remove the ## Missing context section from yact-prompt.md by hand, then run y act (or y -s next act) directly, skipping y plan. With the section gone, that gate no longer blocks act, and the steps proceed with whatever context is already linked. If a step then genuinely fails for lack of context, link the file yourself with y read or y keyword rather than asking y plan to find it again.

See Troubleshooting in the README for other errors and how to resolve them.
