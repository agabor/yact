YACT

YACT (Yet Another Coding Tool) is a command-line tool for AI-assisted coding that I built for my own work. This site describes how it works, the principles behind it, and how to try it.

Gábor Angyal · v0.12.0 · GNU GPL v3

Why I built it

Partly as a way of learning. And partly because agentic development took the control out of my hands. An agent explores the code, decides, edits and runs things in a loop, and the person is asked to step in now and then: a human in the loop.

I wanted it the other way round, AI in the loop: I make the decisions and stay in the codebase, and the model does a well-defined job inside that.

The idea

Before the model writes any code, it writes a plan. The plan names the file each step changes, the files the model needed but did not get, and every decision it made because the prompt did not say. Those are resolved first, by a person. Then one model call writes the code. The change is checked against the plan, and the plan goes to whoever reviews it.

What it is

  • A single Go binary, y, that calls Anthropic's API. One command is one API call: no agent loop, no tool use, no background process.
  • A plain Markdown file, yact-prompt.md, that holds the prompt and then the plan.
  • A handful of system prompts, plain text files you can read and change. Each one is a command: plan, act, ask, analyze, review, bash.
  • Open source under the GNU GPL v3.

State of the project

  • A personal project with one maintainer. It changes often, and features come and go: step-by-step execution, the split command, strict mode and skills were all removed in November 2026.
  • The current release is v0.12.0, with binaries for Linux, macOS and Windows. This site describes that version.
  • It works only with Anthropic's API and your own key. You pay Anthropic for the tokens; every call prints its cost.
  • The benefits described here come from my own use. They are not measured.
  • There is no support promise. Issues and pull requests are welcome.

YACT is not made or endorsed by Anthropic.
